# 候选点数量控件样式设计

## 背景

候选点数量控件使用了没有 CSS 定义的 `form-label`、`form-input` 和
`form-hint` 类，导致浏览器显示默认的浅色数字输入框，标签和提示文字也比
周围控件更大，与现有深色界面不一致。

## 目标样式

仅调整候选点数量控件的外观，不改变默认值、输入范围、校验或请求逻辑。

- 控件组与上方出行方式保持 12px 的顶部间距。
- 标签字号为 12px，字重 600，颜色使用 `var(--text2)`。
- 标签与输入框之间间隔 6px。
- 输入框占满可用宽度，使用 `box-sizing: border-box`。
- 输入框内边距为 `7px 10px`，字号为 13px。
- 输入框背景使用 `var(--surface)`，文字使用 `var(--text)`。
- 边框使用 `1px solid var(--border)`，圆角为 8px。
- 获得焦点时边框颜色切换为 `var(--primary)`。
- 提示文字字号为 11px，颜色使用 `var(--text2)`，顶部间距为 5px。

## 实现边界

在 `static/index.html` 中增加候选点控件专用样式类，并替换当前未定义的
通用类名。样式只作用于该控件，不修改其他输入框，也不引入新的全局表单
组件体系。

## 验证

- 静态检查确认标签、输入框和提示分别使用专用类。
- 浏览器确认输入框为深色背景，标签 12px、输入值 13px、提示 11px。
- 输入框默认值仍为 10，允许范围仍为 1–20。
- 现有前端测试和浏览器控制台无错误。
